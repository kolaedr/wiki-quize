# Етап 3 — Зростання

**Мета:** масштабування контенту, мов і retention-механік. Пункти незалежні — порядок за трафіком і фідбеком.

## 3.1. Мови DE / ES / FR

- [ ] Шаблони питань під кожну мову (артиклі/роди), UI-переклади
- [ ] Активація вимоги лейблів → ресинк; моніторинг розміру пулу per-lang (якщо просідає — окремі пороги sitelinks)

## 3.2. Пов'язані теми і рекомендації

- [ ] Перетини класів P31/P279 і властивостей між темами → «схожі ігри» на екрані результату
- [ ] Кросс-тематичні колоди (мікс сутностей кількох тем зі спільними полями)

## 3.3. Адаптивна складність

- [ ] Агрегація правильності відповідей по картці/сутності (`sessions.answers`)
- [ ] Емпірична складність картки поверх `difficulty_score`; калібрування колод (крива легкі→складні)
- [ ] Відсів «зламаних» карток (усі відповідають неправильно → на розгляд)

## 3.4. Соціальне

- [ ] Лідерборди: daily / гра / тиждень (обережно з privacy: нікнейми)
- [ ] Дуелі: розвиток челендж-лінка з етапу 2 у реальні дуелі (запрошення, серії, рахунок H2H)
- [ ] Профілі творців: публічний список ігор, лічильники плеїв

## 3.5. Режим для вчителів (пріоритетний пункт етапу)

Приватні класні групи: вчитель створює групу, призначає колоди, бачить результати учнів.

- [ ] Модель груп: groups, memberships (invite-код/лінк), assignments, результати per-учень
- [ ] Екран вчителя: призначити колоду, дедлайн, зведення результатів класу
- [ ] Два джерела контенту: (а) стандартні wiki-генеровані колоди (вчитель тільки виключає сутності); (б) **кастомні колоди вчителя** — власні питання/картки
- [ ] Кастомні колоди: конструктор питань під наші ж механіки (choice, true/false...), **жорсткий скоуп**: живуть тільки в приватній групі, не потрапляють у каталог/пошук, позначені «контент вчителя, не перевірено вікі» — це єдиний виняток з принципу незмінності фактів
- [ ] Privacy для неповнолітніх: жодних публічних профілів учнів, мінімум даних (нік у межах групи)

## 3.6. Аудіо-картки (design-first)

Цікаво (гімни, спів птахів P51, вимова — «чий це гімн?» унікальна фіча), але складно: медіа, CORS, iOS-політики autoplay. Аудіо **не зберігаємо** — тільки hotlink з Commons.

- [ ] Дизайн-дока: UX аудіо-картки (плеєр, стан без звуку), перевірка CORS/Range-запитів до upload.wikimedia.org, iOS autoplay
- [ ] Розвідка покриття: скільки сутностей мають P51/аудіо у наших темах — чи набирається тема
- [ ] Прототип механіки `audio-choice` тільки після позитивної розвідки

## 3.7. Дистрибуція

- [ ] PWA-поліш: install prompt, офлайн-пак колод (основа PWA — вже з етапу 1)
- [ ] Capacitor-обгортки для сторів — **тільки якщо є трафік** (свідомо уникаємо сторів на старті)
- [ ] SEO-сторінки категорій/ігор (SSR у Next вже є)
- [ ] Embed-віджет: гра як iframe для блогів/освітніх сайтів — канал дистрибуції, синергія з режимом вчителів

## 3.8. Опційно / ідеї на потім

- Сезонні/тематичні добірки на головній (кураторські)
- Досягнення (badges) за стріки і покриття колекцій
