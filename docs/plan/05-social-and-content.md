# Соціальний шар, per-language слайси та контент-карта

*Ідеї 2026-07-23. Частина зроблена (стартові картки, сід категорій), частина —
розписана для наступних ітерацій (команди/інвайти/челенджі — це нова підсистема
зі схемою, робимо після узгодження).*

## Зроблено зараз
- **Стартові картки на головній**: «Просто грай — без реєстрації» (→ демо/каталог)
  і «Зареєструйся, щоб зберігати прогрес» (жарт про команду; ховається, коли вже
  залогінений).
- **Сід категорій 9×кілька = ~45 категорій з вкладеністю** (`db:seed:categories`):
  Географія, Транспорт, Військова справа, Історія, Наука, Природа, Медицина,
  Культура, Технології — кожна з підкатегоріями.

## Соціальний шар (наступна підсистема — СПЕРШУ УЗГОДИТИ)

### Схема (нові таблиці)
- `teams` { id, name, ownerId, createdAt }
- `team_members` { teamId, userId, role: owner|member, joinedAt } — юзер може бути
  в КІЛЬКОХ командах.
- `invites` { token, teamId, inviterId, createdAt, expiresAt? } — реферальний токен.
- `referrals` { userId, invitedByUserId, teamId } — хто кого привів і в яку команду.
- `challenges` { token, gameId, teamId, authorId, seed, createdAt } (розширення
  наявної `challenges`).

### Інвайт-лінк
- Лінк виду `/join?inv=<token>`. Проблема: месенджери відкривають у вбудованому
  вебвʼю і гублять query. Рішення: сторінка-проміжок, що **форсить зовнішній
  браузер** (кнопка «Відкрити в браузері» + `target=_blank`, і зберігаємо токен у
  cookie/localStorage одразу на випадок in-app).
- Після відкриття: якщо не залогінений → реєстрація, і на реєстрації токен →
  привʼязка `referrals` (inviter + team). Якщо залогінений → приєднання до команди.

### Дашборд команди (власник)
- `/team/[id]`: список учасників + їхня статистика (зіграно, очки, серії) з
  `sessions`. Лише owner бачить чужу статистику.

### Челенджі
- Власник кидає челендж на конкретний квіз: `/challenge?ch=<token>` (той самий
  принцип зовнішнього браузера). Юзер у команді → приєднується до челенджа; не
  зареєстрований → реєстрація в команду + приєднання. Порівняння результатів на
  тому самому seed.

## Per-language / per-country слайси (важливо)
Мета: «хочу підтягнути українських науковців/музикантів українською» — тобто
датасет = клас + ФІЛЬТР по країні/громадянству + мова UK.

Потрібне розширення білдера:
- `TopicDef.filters?: { prop: string; valueQid: string }[]` — напр.
  `{ prop: "P27", valueQid: "Q212" }` (громадянство = Україна). Додати AND-клаузу
  в `buildTopicQuery`/`buildEntityQuery`/`buildQidListQuery`.
- У формі: після вибору класу — опційний «фільтр по країні» (пошук країни словом
  → QID) і вибір мови (вже є `locales`; для укр-контенту root лишається en, а uk
  доливається; АБО дозволити змінити root на uk для суто локального датасету).
- ISO-логіка: назви категорій уже per-locale по ISO. Для контенту — `locales`
  визначає, з яких мовних Вікіпедій тягнемо лейбли/лінки. Так «історичні події
  України українською» = клас події + filter P17=Q212 + locales ["uk","en"].

## Контент-карта пріоритетних датасетів (для швидкого білду)
Пиши ці слова в пошук класу; поле-картинка вже пре-вибране.

**Географія**
- Країни: `country` (Q6256) · поля: flag (P41), coat of arms (P94), capital (P36),
  population (P1082), area (P2046), official language (P37).
- Столиці/міста: `city` (Q515) або `big city` (Q1549591) · image (P18), country (P17).

**Транспорт (пріоритет — дитина)**
- Автобренди: `automobile manufacturer` (Q786820) · logo (P154), country (P17).
- Моделі авто: `automobile model` (Q3231690) · image (P18), manufacturer (P176),
  inception (P571).
- Літаки: `airliner` / `aircraft model` · image (P18), manufacturer (P176).

**Військова справа + Історія (поточний фокус)**
- Стрілецька зброя: `firearm` (Q12796) · image (P18), country of origin (P17),
  manufacturer (P176), service entry (P729).
- Військова авіація: `military aircraft` (Q216916) · image (P18), manufacturer,
  country.
- Бронетехніка: `tank` (Q12876) · image (P18), country, service dates.
- Битви: `battle` (Q178561) · image (P18), point in time (P585), location (P276),
  participant/country (P17).
- Війни: `war` (Q198) · image, start/end (P580/P582).
- Історичні постаті: `human` (Q5) + ФІЛЬТР (напр. P106 occupation, або P27 країна)
  — БЕЗ фільтра клас Q5 завеликий; тут потрібні per-country/occupation слайси
  (див. вище).

**Наука**
- Науковці: `human` + filter occupation `scientist` (P106=Q901).
- Хімічні елементи: `chemical element` (Q11344) · symbol, atomic number.
- Винаходи: `invention` · image, inception, country.

**Природа**
- Тварини: `taxon` (Q16521) завеликий → бери конкретні (`bird` кладу окремо, або
  filter). Практично: `species of mammal` тощо — уточнити на пробі.

## Порядок наповнення (за пріоритетом юзера)
1. Країни (розвиток) — вже.
2. Авто: бренди + моделі (дитина).
3. Військова техніка (зброя, авіація, бронетехніка) + битви/війни (історія).
Далі — наука, природа, культура.
